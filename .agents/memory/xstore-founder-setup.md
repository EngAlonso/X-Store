---
name: X-Store first founder setup
description: Preserve the one-time setup flow for the platform's first owner account.
---

Keep platform-owner registration available only before the first owner is created. After successful creation, return to regular sign-in and do not reopen the founder setup to create another owner.

**Why:** The user explicitly asked to preserve the first-time founder registration system; this flow grants the highest platform role.

**How to apply:** When changing authentication or bootstrap behavior, preserve the server-side first-owner gate as well as the UI's status-based choice between founder setup and normal sign-in.
