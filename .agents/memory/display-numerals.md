---
name: Latin numerals across X-Store
description: Display convention for numeric, date, and identifier values throughout the store interface.
---

Use Latin digits (0–9) for user-visible numeric values throughout X-Store, including money, quantities, dates, chart labels, invoice identifiers, and static examples. Keep Arabic interface text and do not rewrite stored business data just to change how it is displayed.

**Why:** the user requested that all numbers on the site appear in English digits.

**How to apply:** use Arabic locale formatting with the Latin numbering system for localized dates and currencies; normalize displayed identifiers or free-text values when they contain Arabic or Persian digits.
