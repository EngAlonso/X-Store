---
name: POS long-shift comfort
description: X-Store point-of-sale readability and visual comfort preference
---

For X-Store's point of sale, the user wants a professional, attractive interface that is not monotonous and remains comfortable on the eyes during extended use.

**Why:** the user stated this requirement for cashiers using the screen for long periods.

**How to apply:** use restful colors, clear visual hierarchy and readable text; avoid tiny labels, harsh contrast and large saturated surfaces.
