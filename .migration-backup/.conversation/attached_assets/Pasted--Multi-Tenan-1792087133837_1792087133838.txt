أريد بناء منصة سحابية متكاملة ومتجاوبة لإدارة المخازن ونقاط البيع بنظام تعدد المستأجرين (Multi-Tenant SaaS POS & Inventory System) تعمل بكفاءة على شاشات الكمبيوتر والهواتف الذكية وتناسب مختلف الأنشطة التجارية (ملابس، أحذية، قطع غيار، سوبر ماركت، إلخ).

يرجى الالتزام بالمتطلبات والمواصفات الفنية التالية في بناء النظام:

1. هيكلية الحسابات والصلاحيات والتحكم المطلق:
- لوحة تحكم مالك المنصة الرئيسي (Super Admin - حسابي أنا): يجب أن تمنحني لوحة التحكم صلاحية كاملة ومباشرة للوصول إلى قاعدة البيانات، والقدرة على قراءة، تعديل، أو حذف أي بيانات تخص أي مستأجر أو مشترك دون أي قيود، وذلك لتقديم الدعم الفني الكامل وحل المشاكل التقنية للمشتركين. وتشمل إدارة الحسابات، تفعيلها، وإيقافها وتتبع الاشتراكات.
- لوحة تحكم صاحب العمل/المحل (Tenant Admin): لإدارة الفروع، المخازن، المنتجات، وتعيين العمال والموظفين مع تحديد صلاحيات مخصصة لكل منهم.
- حساب الكاشير: واجهة بيع مبسطة وسريعة تمتلك صلاحيات (البيع، المرتجع، الاستبدال، وطباعة الفواتير فقط) دون صلاحية رؤية الأرباح أو التقارير الماليّة أو تعديل الأسعار.
- حساب مسؤول المخزن: يمتلك صلاحية إضافة البضاعة وتعديل كميات المخازن فقط.
- حساب المحاسب: يمتلك صلاحية الاطلاع على التقارير المالية والأرباح والخسائر.

2. الميزات الأساسية للنظام (Core Features):
- مرونة المنتجات (Product Variants): دعم إضافة خصائص متعددة للمنتج مثل اللون والمقاس (للملابس والأحذية)، تاريخ انتهاء الصلاحية (للسوبر ماركت)، ورقم القطعة الأصلية (لقطع الغيار).
- نظام الاشتراكات: دعم باقات مرنة تشمل (اشتراك شهري، نصف سنوي، سنوي، واشتراك مفتوح مدى الحياة Lifetime لا ينتهي تلقائياً) مع نظام تنبيهات تلقائي قبل انتهاء الاشتراك.
- دورة عمل الكاشير (POS Workflow):
  * البيع السريع: دعم قارئ الباركود والبحث السريع، وطباعة الفواتير المتوافقة مع الطابعات الحرارية (Thermal Printers).
  * المرتجع (Returns): إرجاع المنتج برقم الفاتورة الأصلية بحيث يعود للمخزن تلقائياً وتُخصم قيمته من الخزينة.
  * الاستبدال (Exchange): إجراء عمليتي مرتجع وبيع جديد في نفس الوقت وحساب الفرق المالي بدقة.

3. المتطلبات التقنية المقترحة:
- الواجهة الأمامية: React.js أو Next.js مع مكتبة Tailwind CSS لضمان سرعة فائقة وتجاوب كامل مع الكمبيوتر والموبايل (Responsive).
- الخلفية وقاعدة البيانات: Node.js أو Laravel مع قاعدة بيانات PostgreSQL أو MySQL، مع تطبيق معمارية عزل البيانات لكل مستأجر (Tenant Isolation via tenant_id) مع الإبقاء على صلاحية التحكم والوصول الشامل والكامل للـ Super Admin.
